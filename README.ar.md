# Hussein Badr English

منصة تعليمية مجانية لتعلّم الإنجليزية من A1 إلى C1: دروس قصيرة، مرجع قواعد، مفردات بالنطق، بطاقات مراجعة متباعدة، اختبار مستوى، ولوحة تقدم محفوظة على جهاز المستخدم. موقع ثابت بالكامل (HTML/CSS/JS) بلا خادم.

**الموقع:** https://gnathussinbder-star.github.io/Hussien-/

## هيكل الملفات
| المسار | المحتوى |
|---|---|
| الصفحات في الجذر | الرئيسية، المسارات، الدروس (18)، الاختبارات، التمارين، البطاقات، الأسئلة الشائعة… |
| `grammar/` | 12 موضوعًا في القواعد مع جداول وأمثلة وأخطاء شائعة واختبار |
| `vocabulary/` | 10 موضوعات مفردات (12 كلمة لكل موضوع) |
| `levels/` | دليل كل مستوى A1–C1 |
| `assets/css` · `assets/js` · `assets/img` | التنسيق والسكربتات والصور |
| `sw.js` · `manifest.webmanifest` | العمل دون اتصال وتثبيت الموقع على الهاتف |
| `tools/validate.py` | فحص الروابط والصور وخريطة الموقع والوسوم |

## التشغيل والفحص
```
python3 -m http.server 8000
python3 tools/validate.py
```

## الهوية البصرية

## النشر
ارفع المحتويات إلى المستودع، ثم Settings ← Pages ← فرع `main` والمجلد `/ (root)`. الملف `.nojekyll` موجود لتجنب معالجة Jekyll.
